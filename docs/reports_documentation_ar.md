# دليل التقارير في تطبيق المحاسب

## نظام التقارير المتكامل

تم تطوير نظام تقارير شامل يتصل مباشرة بقاعدة البيانات ويقدم معلومات مالية ومحاسبية دقيقة في الوقت الفعلي.

---

## 📊 تقارير المحاسبة

### 1. **ميزان المراجعة (Trial Balance)**
- **الوصف**: عرض جميع الحسابات مع أرصدتها المدينة والدائنة للتأكد من توازن القيود المحاسبية
- **البيانات المعروضة**:
  - أرقام وأسماء الحسابات
  - الأرصدة المدينة والدائنة
  - إجمالي المدين والدائن
  - التحقق من التوازن
- **الحالة**: ✅ منفذ ويعمل

### 2. **قائمة الدخل (Income Statement)**
- **الوصف**: عرض الإيرادات والمصروفات وصافي الربح أو الخسارة للفترة المحددة
- **البيانات المعروضة**:
  - الإيرادات بأنواعها
  - المصروفات التشغيلية
  - المصروفات الإدارية والعمومية
  - صافي الربح/الخسارة
- **الحالة**: ✅ منفذ ويعمل

### 3. **الميزانية العمومية (Balance Sheet)**
- **الوصف**: بيان المركز المالي للمنشأة في تاريخ محدد
- **البيانات المعروضة**:
  - الأصول (المتداولة والثابتة)
  - الخصوم (قصيرة وطويلة الأجل)
  - حقوق الملكية
  - معادلة الميزانية
- **الحالة**: 🔄 قيد التطوير

### 4. **التدفقات النقدية (Cash Flow)**
- **الوصف**: حركة النقد الداخل والخارج من الأنشطة التشغيلية والاستثمارية والتمويلية
- **البيانات المعروضة**:
  - التدفقات من الأنشطة التشغيلية
  - التدفقات من الأنشطة الاستثمارية
  - التدفقات من الأنشطة التمويلية
  - صافي التغير في النقد
- **الحالة**: 🔄 قيد التطوير

### 5. **دفتر الأستاذ العام (General Ledger)**
- **الوصف**: سجل تفصيلي لجميع الحركات المحاسبية لكل حساب
- **البيانات المعروضة**:
  - تفاصيل كل قيد محاسبي
  - التواريخ والمبالغ
  - الأرصدة التراكمية
  - البيان والمرجع
- **الحالة**: 🔄 قيد التطوير

### 6. **تقرير اليومية (Journal Report)**
- **الوصف**: عرض القيود اليومية بالتسلسل الزمني
- **البيانات المعروضة**:
  - رقم القيد
  - التاريخ
  - الحسابات المدينة والدائنة
  - البيان
- **الحالة**: 🔄 قيد التطوير

### 7. **كشف حساب (Account Statement)**
- **الوصف**: تفاصيل حركة حساب محدد خلال فترة زمنية
- **البيانات المعروضة**:
  - الحركات المدينة والدائنة
  - التواريخ والبيانات
  - الرصيد التراكمي
  - الرصيد النهائي
- **الحالة**: ✅ منفذ ويعمل

### 8. **تقرير الحركات (Transactions Report)**
- **الوصف**: عرض شامل لجميع القيود والحركات المحاسبية
- **البيانات المعروضة**:
  - القيود من جداول journal_entries
  - الفواتير من جداول invoices
  - التصنيف حسب النوع (مبيعات، مشتريات، قبض، صرف، إلخ)
  - إمكانيات الفلترة والترتيب
  - التصدير إلى PDF وExcel
- **الحالة**: ✅ منفذ بالكامل ومتصل بقاعدة البيانات

## 🔧 المميزات التقنية

### البنية التقنية للتقارير:
1. **Clean Architecture**: فصل كامل بين الطبقات (Domain, Data, Presentation)
2. **State Management**: استخدام Cubit لإدارة الحالة
3. **Database Integration**: اتصال مباشر مع قاعدة البيانات SQLite
4. **Real-time Data**: البيانات محدثة وفورية من قاعدة البيانات
5. **Export Options**: إمكانية التصدير إلى PDF وExcel
6. **Filtering & Sorting**: خيارات متقدمة للفلترة والترتيب

### الجداول المستخدمة:
- `journal_entries`: القيود المحاسبية
- `journal_entry_lines`: تفاصيل القيود
- `invoices`: الفواتير
- `invoice_lines`: تفاصيل الفواتير
- `accounts`: دليل الحسابات
- `customers`: العملاء
- `suppliers`: الموردين
- `categories`: المنتجات

### أنواع الحركات المدعومة:
- **sales**: مبيعات
- **purchase**: مشتريات
- **journal**: قيد يومية
- **receipt**: قبض
- **payment**: صرف
- **opening**: رصيد افتتاحي
- **salesReturn**: مردود مبيعات
- **purchaseReturn**: مردود مشتريات
