## 1. الملخص التنفيذي — لماذا تبدو الـ Enums غير مُستخدمة؟

بعد فحص **88** جملة `switch` و **48** تعريف `enum` (43 نوعًا مميزًا) تبيّن أن **المشكلة ليست قلة الـ Enums بل سوء توزيعها وانقطاع سلسلة التحويل**:

| السبب الجذري | الشرح | أثره |
|---|---|---|
| **1) الترحيل الجزئي — Enums موجودة لكن الطبقات العليا تتجاوزها** | أنشأ الفريق Enums مركزية ممتازة في `lib/core/enums/` (`InvoiceStatus`, `AccountConnectType`, `TransactionType`...) لكن الـ `Entity` والـ `Model` لا تزال تخزّن الحقل كـ `int`/`String`. فتضطر الـ UI لعمل `switch(status)` على الرقم الخام بدلًا من `switch(statusEnum)` | 19 حالة `switch` تعمل على `int` رغم وجود Enum مطابق — انظر القسم 5 |
| **2) الازدواجية المحلية (Local Shadowing)** | 5 أنواع مُكررة بنفس الاسم في ميزات مختلفة: `PaymentMethod`×3 و `DiscountType`×2 و `InvoiceType`×2 و `VoucherType`×2. كل ميزة صدّرت `enum` ناقص (مثلاً `sale_invoice_models.dart:228` فيه `cash/bank/deferred` فقط بينما المركزي فيه 5 قيم) | يمنع تمرير القيمة بين المبيعات والمحاسبة والتقارير دون تحويل يدوي |
| **3) التخزين الخام في SQLite بدون طبقة تحويل** | الجداول تحفظ `invoice_type=1`, `status=1`, `connect_type=2`, `reference_type='sales'` كأرقام/نصوص. الـ `DataSource` يُمرّر الرقم كما هو بدل تحويله بـ `fromValue()` فور القراءة | 60% من الـ UI تضطر لإعادة تفسير الرقم |
| **4) مفاهيم بلا Enum أصلاً** | مفاهيم أساسية تُدار كـ `String`/`int` سحري: تسلسل الترقيم (`sales_invoice` string), فلاتر المدة السريعة (`'today'/'week'`), خطوات المعالجات (`_currentStep = 0,1,2`), إعدادات الطباعة (`printType 1/2/3`) | 27 حالة `switch` لا يوجد لها Enum إطلاقًا — القسم 8 |
| **5) تضارب التعيين الرقمي (Mapping Mismatch)** | أخطر ثغرة: `InvoiceStatus` المركزي `0=draft,1=open,2=approved` بينما تقارير `invoices_list_report_page.dart:110` و `invoice_report_components.dart:162` تفترض `1=مرحلة,2=مسودة,3=ملغاة,4=مرتجعة` — تعيين مختلف تمامًا! | ألوان وشارات الحالة قد تظهر بالخطأ |

> **الخلاصة:** الـ Enums ليست "بلا فائدة" — هي **معزولة**. إصلاح طبقة التحويل (`fromValue` في Model + حذف المكررات + توليد Enums ناقصة) سيحوّل كل `switch` خام إلى `switch` استيعابي آمن.

    return partial;
  }
}
